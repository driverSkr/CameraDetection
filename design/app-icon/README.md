# App icon

用户确认的最终图标：白色摄像头、红色扫描线与命中标记、四角取景框，前景采用确认后的放大 12% 比例。

- `icon_foreground.png`：1024 × 1024，保留 Alpha 的前景源图。
- `icon_background.png`：1024 × 1024，纯色背景 `#082A23`。
- `export.py`：通过 Pillow 导出项目中五档密度的 20 张无损 WebP 图标，并检查尺寸。

运行 `python design/app-icon/export.py` 可重新导出。前景/背景使用 108dp 分层画布；普通与圆形兼容图标按中央 72dp 可见区域生成。原有自适应 XML 和 Manifest 继续引用同名资源。

前景沿用最终确认的留白，不要再自动裁边。主体位于中央，外侧取景框部分进入核心 66dp 安全区以外，符合已确认的放大设计；启动器动画可能改变外围装饰的裁切。
