日期：2026-09-14

本轮落实已审核的 10 项 P1 方案及扫描网络范围、UDP 协议发现、两个 Lint 错误的关联修复。未发布线上版本、未提交 Git、未执行实际扣费。

## 逐项结果

| 编号 | 原问题 | 本轮实现 |
|---|---|---|
| P1-01 | 除本机外默认全部可疑 | 设备类型、Finding、用户信任分别保存；无证据为信息不足；摄像头相关特征才计入提示数量；本机不参与。用户信任可撤销且不改变协议证据。 |
| P1-02 | 单端口确定设备类型 | 删除 5000=摄像头、80/443=路由器等推断。使用真实 Wi-Fi 网关、RTSP 响应、mDNS PTR、SSDP 响应、ONVIF ProbeMatch 证据；仅开放端口不等于摄像头。结果展示依据与规则版本。 |
| P1-03 | 切换标签丢失扫描任务 | 新增 Activity 级 ScanViewModel，页面订阅统一状态。切换标签不中断任务；配置重建保留 ViewModel；进后台取消；保存中断标记，重新进入或进程恢复可显示中断原因。 |
| P1-04 | 取消不关闭底层任务 | ScanResources 统一追踪并关闭 Socket/DatagramSocket；停止后拒绝新的资源；旧扫描代次不得更新新扫描。使用固定数量的协程工作者代替逐设备建线程。 |
| P1-05 | 超时错误地视为完成 | 移除 join(3000) 和无限 latch.await。设备分析预算 8 秒、单次分析请求约 1.5 秒、整体 45 秒；超时保留已发现证据，显示部分完成。取消与超时实际关闭网络资源。 |
| P1-06 | 失败被当成空成功 | 显式区分完成、部分完成、失败、取消；无 Wi-Fi、纯 IPv6、地址不可用等给出原因；网络变化终止扫描。失败/取消/部分结果不覆盖最近完整记录；埋点分别记录。 |
| P1-07 | 相机承诺与实现不符 | 改为相机辅助检查；默认原始画面，彩色层仅为可选观察效果。加入前后摄切换、硬件支持时的手电筒和缩放、红外遥控器自测指导、权限/初始化失败重试与设置入口。删除未使用的 ImageCapture，按预览用例释放资源。 |
| P1-08 | 购买后无法接续 | 显式购买状态；成功关闭付费页并返回结果，原入口接续；加入回调代次与成功去重、待支付状态、已拥有重新查询、商品缺失/断连/失败处理及重复点击限制。回到前台查询权益恢复。 |

| P1-10 | 默认美元价格伪装商店价格 | 删除写死兜底价格。现代订阅商品一次查询解析各基础方案，展示商店本地化价格；没有可用商品禁用购买并提供重试。购买前重新读取并校验同一方案的价格/周期，变化时回到页面要求重新确认。 |

## 扫描与界面边界

- 网络从 ConnectivityManager/LinkProperties 选择真实 Wi-Fi 接口和 IPv4 前缀；所有连接绑定该 Network，UDP 绑定本机该接口地址。VPN/多网络的真实兼容性仍需多机型覆盖。
- 最多检查 1024 个 IPv4 地址；更大网段明确标记覆盖不完整。发现阶段最多 32 个并发 TCP 请求，分析阶段最多 8 台设备、每台顺序探测服务。
- mDNS/SSDP/ONVIF 使用各自 UDP 协议，不再把 UDP 服务端口当作 TCP 证据。mDNS 压缩指针解析有边界/循环校验；ONVIF 检查请求关联及视频类型命名空间。
- 发现阶段使用组播与有限 TCP 探测，不依赖额外 Ping；无响应不代表设备不存在，离线、隔离网络及其他网络中的设备不在保证覆盖范围内。
- RTSP/ONVIF/mDNS 视频服务仅表示服务线索，不能证明隐藏摄像头；没有摄像头特征不代表房间安全。
- 未加入自动图像识别、后台持续扫描、IPv6 全量扫描、云端设备数据库或跨重启离线订阅宽限。
- Wi-Fi 扫描已不读取定位敏感的 SSID 元数据，因此移除了不再需要的定位及附近 Wi-Fi 权限，而不是增加不必要的授权弹窗。保留必要的网络权限，增加组播锁权限。
- 按后续 UI 审核意见，恢复原雷达、统计卡片、设备列表和底部详情弹窗。百分比接入实际发现/分析进度，取消与失败不显示完成；红点仅在已有检测线索时作为装饰动画出现，设备数量直接读取扫描状态。订阅页恢复原插画、渐变标题、横向套餐卡片和绿色胶囊按钮，小屏通过整体滚动容纳内容。详见 `UI_RESTORATION_REPORT.md`。
- 最近完整历史保存时间、网络地址/前缀、结论、证据和规则版本；旧记录明确标为旧版信息，旧“安全”标记不会自动升级成可信判断，历史在线字段不再当作实时在线状态。
- 现阶段销售原有基础订阅方案；多阶段优惠/试用不会被截取一个价格阶段伪装为完整报价。

## 真机测试期间的意外与恢复状态

自动化测试 APK 被系统安装增强防护拦截。取消安装后，AGP/UTP 测试运行器的默认清理流程卸载了目标业务调试应用。本次没有事先建立机外应用数据备份；扫描历史的临时备份放在应用 cache 内，未能隔离卸载风险。原扫描历史未能保证保全，这是本次操作失误。

业务 APK 恢复安装已返回 Success，没有关闭手机全局防护。恢复后检查确认 `shared_prefs/sp_detect_scan_history.xml` 和 `cache/p1-scan-history-backup.xml` 都已不存在，原扫描历史无法从本次应用内备份恢复。这部分原有本地数据没有保全；恢复应用安装不等于恢复原数据。

已根据本项目 AGP 8.6.0 的 BooleanOption/UtpConfigFactory 源码加入 `android.injected.androidTest.leaveApksInstalledAfterRun=true`，避免今后的 connected 测试结束/失败时自动卸载业务包。后续设备自动化测试应使用独立测试设备或预先完成机外备份。
