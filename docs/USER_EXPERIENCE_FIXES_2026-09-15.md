# 用户体验改进（保留雷达动画）

## 范围

按用户要求保留雷达及随机红点动画，不修改审查报告第一项；实现其余五项。本轮未修改网络扫描超时、端口、并发或探测流程。

## 已实现

1. **结果状态**：其他设备统计改中性色，明确总览属于整次扫描，单列分析未完成数量。普通设备行显示详情箭头，分析未完成显示警告；手动信任单独显示“我的标记”。
2. **筛选与搜索**：筛选区固定在列表顶部，支持名称、型号、主机名和 IP 搜索；类型、视频线索、分析未完成条件可组合。显示当前条数/扫描总数，可清除筛选，无结果提供提示。切换条件回到列表起点；状态按扫描记录保存。长扫描报告可折叠。
3. **详情顺序**：首屏优先显示检测结论、身份依据和下一步建议；提供 IP 复制。MAC、型号补充信息、协议及原始证据收进可展开技术详情，保留全部证据和信任操作。
4. **硬件与服务分离**：媒体播放/媒体服务器公告作为“公告服务能力”展示，不再单凭这些公告确定硬件。明确型号或电脑/移动设备名称线索可给出“疑似”类型；不足时继续显示待确认。设备列表和详情按类型使用不同图标，未知设备使用通用图标。
5. **Wi-Fi 入口一致**：功能页 Wi-Fi 进入检测页，不再自动启动；保留正在进行的扫描及已有结果，由用户点击开始或重扫。

## 验证重点

身份与服务能力分离、名称推测边界、功能入口不自动扫描、结果筛选/搜索/清除、固定筛选区、展开技术详情及大字体下地址排布。此前依赖媒体公告直接分类和入口自动开始的旧测试已按新行为更新。
