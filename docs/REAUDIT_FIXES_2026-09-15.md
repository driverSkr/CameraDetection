# 复审问题修复

## 完成的 5 项修复

1. **组播有限重试**：mDNS/SSDP/ONVIF 初始请求最多发送 3 次，计划在第 0、750、1500ms 各发送一次，接收窗口 3 秒。未解析的 mDNS SRV/A 查询间隔至少 500ms、最多 3 次；已解析后不再请求。TCP 的 32/48/64 并发、五个端口、450ms 超时保持不变；组播与 TCP 并行。
2. **详情布局**：IP、MAC、型号改成标签与数值上下排布，按内容高度布局，避免大字号挤在同一行。
3. **历史读取失败**：新增独立的读取失败状态，扫描页及结果页显示重试入口。新历史覆盖无法解析的原文件之前，先保存字节一致的独立备份；备份失败会阻止覆盖。写入缓存避免每次检查点重复解码同一个已保存文件。重读结果不会覆盖读取期间已经产生的新扫描记录。
4. **订阅提示**：商品加载错误使用独立状态，开始重试时清除、成功后保持清空，不清除购买流程自己的提示。
5. **无障碍**：详情关闭、相机返回/关闭帮助/重置、设置返回、结果页返回和订阅页关闭按钮补充中英文操作名称。
