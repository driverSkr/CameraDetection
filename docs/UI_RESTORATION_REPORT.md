# UI 恢复与风格统一汇报

本次根据用户要求，以 Git HEAD `d1150af` 中的原有 UI 为参照，将上一轮修复中改写的页面恢复为原有视觉结构，再接入已经修复的逻辑。

## 修改范围

| 页面 | 恢复的原有 UI | 在原 UI 内保留或补充的逻辑 |
| --- | --- | --- |
| Wi-Fi 扫描 | 原背景、标题、雷达、居中百分比、底部 Start / Cancel / Recheck / Result / History 按钮 | Activity 级扫描状态、取消与中断提示、真实发现/分析进度、订阅临时放行 |
| 结果列表 | 原返回栏、红绿统计卡片、数量徽标、圆角设备行、订阅遮罩 | 检测线索与其他设备的准确文案、不完整状态、历史说明、设备详情访问控制 |
| 设备详情 | 原底部弹窗、拖动条、设备图标、IP/MAC/型号字段、绿色胶囊按钮 | 检测依据、分析是否完整、用户信任标记与撤销；未知信息不显示为安全 |
| 相机 | 原 Scanner 标题栏、全幅预览区域、上下渐变遮罩、提示条、红绿蓝圆形选择器、重置图标 | 原图选择器；同风格的镜头切换、补光、绿色缩放条；保留权限、生命周期、硬件能力与错误重试处理 |
| 订阅 | 原背景插画、光锥叠图、渐变标题、权益列表、横向套餐卡片、绿色 Continue、协议链接 | 商店真实价格、加载/失败/重试、购买状态与按钮禁用、恢复购买；小屏整体滚动 |
| 其他页面 | 核对磁场页、相机入口页、功能页、引导页、设置页 | 原布局保留；相机入口标题恢复为 Scanner，必要说明及异常处理继续保留 |

统一沿用原项目绿色 `#00C46F`、深色背景、White/White60/White10、原字体层级、圆角和图标资源。新增按钮沿用项目已有样式，避免混入另一套默认按钮或卡片外观。

扫描页删除的旧代码主要是页面内扫描执行器和定时伪进度；这些逻辑已由 ScanViewModel / NetworkScanner 承接，并非再次删减 UI。
