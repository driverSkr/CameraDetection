# SpyFinder 新 UI · 产品说明（v3）

> 配套：设计画布《SpyFinder UI 交付包（产品版 + 开发版）》产品版板块。

## 设计方向（方向 C）

**浅色信任壳 + 深色检测沉浸**——日常页面浅色、可信、工具感；进入扫描/相机/订阅时切换深色沉浸，
形成「进入工作状态」的仪式感。单一品牌蓝（#0066CC）贯穿全局。

## 三条设计原则

1. **信任壳 + 工作态**：反偷拍工具的用户警惕性最高，界面必须像专业工具而非"演出"。
2. **一屏一焦点**：每屏只有一个视觉重心，用主视觉图和数字替代大段文字（对比旧版文字过多的问题）。
3. **真实数据可视化**：雷达、进度、红点全部对应真实扫描结果，真实性 = 付费信任。

## 页面与价值

| 页面 | 模式 | 价值 |
|---|---|---|
| 01 首页 | 浅色 | 当前 Wi-Fi + 待核实(3)/已确认(5) 双数字卡，唯一 CTA，零学习成本 |
| 02 扫描中 | 深色 | 专业雷达仪表（进度/发现数/可取消），把等待变成确定性，降低流失 |
| 03 检测结果 | 浅色 | 红=风险 / 绿=安全语义色，逐台核实，结果沉淀为信任资产 |
| 04 相机检查 | 深色 | 全屏取景 + 红绿蓝滤镜，真实镜头反光检测原理，差异化卖点 |
| 05 订阅 | 深色 | 图标化权益 + 周/年对比（年卡引导），替代旧素材拼贴风，服务转化 |

## 用户主流程

打开 App（状态总览）→ 开始网络检测 → 实时扫描（深色沉浸）→ 结果核实（红/绿）→ 订阅解锁

## 与旧版（main 分支）的关键差异

- 移除随机红点/假百分比的"剧场感"，改为真实数据仪表
- 移除位图拼贴素材体系，统一为「插画级 3D 主视觉 + 线性图标」双轨
- 建立设计 Token 与语义色体系，替代 100+ 处散落硬编码色值
