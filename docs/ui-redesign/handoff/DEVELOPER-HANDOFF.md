## 1. 全局约定

- **双模式**：浅色「信任壳」（首页/结果等日常页）+ 深色「检测沉浸」（扫描/相机/订阅）。
  现有 `theme/Theme.kt` 需重建：删除默认紫色 Material 主题与 dynamicColor，按本 Token 表建立
  `SpyFinderLightColorScheme` / `SpyFinderDarkColorScheme`，按路由切换。
- **全局 density 覆盖要移除**：main 分支的 393dp 缩放 hack 会干扰新布局，落地时去掉，改用标准 dp/sp。
- **字体**：数字/英文 Inter（SemiBold/Bold），中文 Noto Sans SC（Regular/Medium/SemiBold）。
  工程内统一走 `Typography` 扩展，禁止页面内散落 fontSize。

## 4. 雷达（扫描页）分层与动画

**v2 改动（对齐 main 分支观感）：底纹与光束改为两张位图叠加，不再用 SVG 描边圆环 + 硬扇面。**
原因：main 分支的雷达是「径向底纹 + 整体旋转的第二张图」，实机观感圆润丝滑；纯矢量扇面会出现硬前沿和阶梯边缘。
素材由 `assets/gen_radar_assets.py` 解析式生成（01200² RGBA PNG，数学函数直出、无模糊后处理），
参数按 `main` 分支 `img_radar_bg / img_radar_detect / img_position` 的**像素实测**标定：

| 层 | 素材 | 形态（实测标定） | 动画 |
|---|---|---|---|
| L1 涟漪底纹 | `sf_radar_ripple.png` | 3 条离散同心环（归一化半径 0.34 / 0.64 / 0.92，环间透明度≈0），峰值 α≈0.27，`#56A8FF` | 静态 |
| L3 扫描光束 | `sf_radar_sweep.png` | **单瓣平滑光弧**：角度高斯瓣，前沿 σ=19°、拖尾 σ=34°，峰值 α≈0.36，两端自然衰减到 0（无硬边），`#5DACFF` | rotate 360°/2s Linear 无限 |
| L4 设备点 | `sf_hit_glow.png` | **实心核 r≤0.5 + 外光晕**（不是纯渐变），峰值 α=1.0，`#FF686C`；画布内尺寸 40×40 | 脉冲 1.2s 循环，位置=扫描结果 |
| L5 进度层 | 大数字 + 进度条 | 数字 Inter SemiBold 44 白 + `%` 14（居中，叠在雷达圆心）；进度条 h6 r999（底 `#272729`/填充 `#2997FF` 或 `#0A84FF`） | 数据驱动 |

实现要点：

- **旋转的只有 L3**（L1 静止），`graphicsLayer { rotationZ = angle }`，`LinearEasing` + `infiniteRepeatable`；
  main 分支的 `RadarScannerWithRepeatable` 就是这么做的，直接沿用其动画参数。
- 三张图按正方形 `ContentScale.FillBounds/Crop` 铺满各自容器（容器即雷达尺寸 344×344，等比缩放到其它尺寸不失真）。
- 红点只在真实扫描命中时出现；命中点位置为容器内绝对坐标。
- 旧的 `L2 刻度环 / 十字轴` 已从设计稿移除——位图底纹自带层次，再叠矢量刻度会显脏。

### 5.1 磁场仪表规格（06 页 · 对应 `SensorPage`）

**v2 改动（对齐 main 分支观感）：渐变圆环与刻度底改用位图（渐变 + 圆头端帽由素材保证），刻度线与指针仍是矢量。**
main 分支用 `img_circular_arc / img_circular_scale / img_circular_pointer` 三张图 + 弹簧动画，圆润感来自「渐变圆环位图 + `DampingRatioMediumBouncy` 弹簧」。

- 画布 300×300，圆心 (150,150)，量程带中心半径 R=118、带宽 18，量程 270°（135° 起 **顺时针** 到 405°，即左下→顶部→右下），**两端圆头端帽**
- 素材：`sf_gauge_ring.png`（检测中）/ `sf_gauge_ring_idle.png`（未开始），由 `gen_radar_assets.py` 生成
  - 色带走 HSV 短弧插值：`212°→190°→170°→52°→32°→357°`，即 品牌蓝→青→安全绿→琥珀→风险红，避免 RGB 插值混出灰调
  - 检测中：α=1.0 + 外发光 0.20；未开始：**降饱和**（s×0.26, v×0.86）α=0.72，读作中性灰刻度带
    *（注意：只压 alpha 不降饱和会让黄/橙段在深底上发脏成土色，这是踩过的坑）*
- 矢量层（SVG `M/L` 折线）：17 根刻度线（r 78→90，`#8FB6E0` w4.5 圆头 α0.35）+ 指针（胶囊形，长 100、宽 13，白）+ 轴心（r11 底 `#0A0A0B` + 描边 `#4DA6FF` w2.5 + 内点 r4）
- 读数：44 Bold 白 + `μT` 15，压仪表下方居中；等级胶囊用 `RiskRed` 14% 底 + `#FF686C` 文字
- 归一化沿用现网实现：`<20 μT → 0%`、`>1000 μT → 100%`，其余线性；**指针旋转 = 180° + 百分比 × 2.7°**
- **丝滑感**关键：指针旋转走 `animateFloatAsState(spring(DampingRatioMediumBouncy, StiffnessLow))`，不要 tween
- ⚠️ 指针/刻度的 SVG 路径统一用折线（`M/L`）实现，纯 `A` 弧命令在画布渲染不稳定（渐变圆环已改为位图，不受此限）

### 5.2 磁场页两态（06 检测中 / 06b 未开始）

同一页面的两个数据态，除下表差异外其余图层完全一致（含底部 TabBar「磁场」选中态）。

| 元素 | 06 检测中 | 06b 未开始（空态） |
|---|---|---|
| 副标题 | `Magnetic Detector · 贴近可疑位置缓慢移动` | `Magnetic Detector · 磁力传感器已就绪` |
| 读数弧 | 0%~62% `#2997FF` | **不绘制**（无数据弧） |
| 指针 | 随读数旋转（62% 位置） | 停留 0% 起点（135°，指向左下） |
| 读数 | `126` μT · 48 Bold 白 | `0` μT · 48 Bold 白 |
| 等级胶囊 | `RiskRed` α14% 底 · `#FF6B70` 字 · 红点 · 「磁场偏强 · 建议重点排查」 | 白 α8% 底 · `#CCCCCC` 字 · 灰点 · 「未开始检测」 |
| 提示卡文案 | 关闭附近电器后重新靠近可疑位置… | 点击下方按钮开始，随后将手机贴近墙面、插座、烟雾报警器等位置缓慢移动… |
| 主按钮 | **次按钮** 样式 `DarkSurface` · 「停止检测」 | **主按钮** 样式 `#0066CC` · 「开始检测」 |

实现要点：状态由传感器订阅开关驱动，`isRunning=false` 时停掉读数动画并归零指针；主按钮样式切换用同一 `PrimaryButton`/`SecondaryButton` 组件，不要各写一套。
